# The knowledge base of Forge.Next.LocalWebShell

For AI sessions (and people) who continue the work on this package. `CLAUDE.md` in the repository root holds the rules;
this folder holds the background, so a new session does not have to rediscover it.

| File | What is in it | Update it when |
| --- | --- | --- |
| `HISTORY.md` | How the package came about, what Zoltán asked for and decided, in order, with the reasons | Zoltán decides something, or asks for a change |
| `DESIGN.md` | How the package works: the parts, the flow of a launch, the browser decision, and why each design choice was made | The code's structure or behaviour changes |
| `VERIFICATION.md` | How to check the package (tests, the elevated Windows check, the Linux check, the real-browser check), and what was run when, with the results | A check is run or a new one is added |
| `OPEN.md` | What is not done or not verified yet, and the questions waiting for Zoltán | An item is closed or a new one comes up |

Keep the files short and factual. Dates are absolute (2026-11-08, not "today"). Write in English.
